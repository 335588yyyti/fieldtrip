# 校外教學行前分組

一個網頁檔（`index.html`）就能完成校外教學的前置作業：學生名單、活動分組、用餐分組、房間分組、遊覽車座位、緊急聯絡資料與特殊照護，每一頁都可以直接列印。

網址：<https://335588yyyti.github.io/fieldtrip/>（需先開啟 GitHub Pages，見下方）

## 使用方式

1. 打開上面的網址，或下載 `index.html` 用 Chrome / Edge / Safari 打開，不需要安裝。
2. 第一次打開會看到範例資料，按「清除範例，開始建立我的名單」後匯入自己的班級。
3. 資料只存在這台電腦的這個瀏覽器裡，不會上傳。換電腦前請在「行程資料」頁下載備份檔。

## 功能

| 頁面 | 說明 |
| --- | --- |
| 行程資料 | 活動名稱、日期、地點、班級；頁面最下方有選填的行程表，可列印；可匯入行程檔（Excel、CSV 或從 Word 表格貼上），匯入前可選擇要套用基本資訊、行程表或兩者 |
| 學生名單 | 可匯入 Excel（.xlsx）、CSV，或從 Excel 複製貼上；男生藍色、女生粉紅色色塊 |
| 活動分組 | 設定組數後依座號或隨機分組（男女平均），可指定組長，拖曳微調 |
| 用餐分組 | 每桌人數可調（預設 10 人），每桌也可以單獨設定；顯示素食等飲食需求 |
| 房間分組 | 每間人數可調（預設 4 人），男女自動分開，不同性別無法拖進同一間 |
| 遊覽車座位 | 座位圖（可調排數、最後一排 5 人座），可多台車；可依座號、依活動組或隨機排座，並可選同性別坐一起；點空位可設為老師保留座 |
| 聯絡資料 | 給導師用：學生手機與兩位緊急聯絡人 |
| 特殊照護 | 總表；另外各分組頁也會註明相關需求：素食與食物過敏標在用餐分組，暈車標在遊覽車座位，其他醫療狀況標在活動與房間分組 |

每個分組頁都有「隨機」按鈕，可以一直按重新抽，直到滿意為止；手動調整過之後再按會先詢問。

「列印本頁」只印目前頁面，「全部列印」一次印出所有名單與分組（名單與聯絡資料自動使用橫向 A4，遊覽車一台一頁）。

## 開啟 GitHub Pages

到 GitHub 專案的 **Settings → Pages**，在 Build and deployment 的 **Source** 選 **GitHub Actions**。之後每次更新 `index.html`，`.github/workflows/pages.yml` 會自動把網頁發布到上面的網址。

網頁本身公開，但學生資料只存在各自的瀏覽器，不會出現在網址上，也不要把真實名單 commit 進這個專案。

## 匯入欄位

第一列為欄位名稱：`座號, 姓名, 性別, 學生手機, 緊急聯絡人1, 關係1, 電話1, 緊急聯絡人2, 關係2, 電話2, 飲食, 過敏/醫療, 備註`。
可在「學生名單」頁下載範本。Big5 編碼的 CSV 與被 Excel 去掉開頭 0 的手機號碼都會自動處理。
