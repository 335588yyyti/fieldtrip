# 校外教學行前分組

一個網頁檔（`index.html`）就能完成校外教學的前置作業：學生名單、活動分組、用餐分組、房間分組、緊急聯絡資料、點名表與特殊照護，每一頁都可以直接列印。

## 使用方式

1. 下載 `index.html`，用 Chrome / Edge / Safari 打開即可，不需要安裝。
2. 第一次打開會看到範例資料，按「清除範例，開始建立我的名單」後匯入自己的班級。
3. 資料只存在這台電腦的這個瀏覽器裡，不會上傳。換電腦前請在「基本資料」頁下載備份檔。

## 功能

| 頁面 | 說明 |
| --- | --- |
| 學生名單 | 可匯入 Excel（.xlsx）、CSV，或從 Excel 複製貼上；男生藍色、女生粉紅色色塊 |
| 活動分組 | 設定組數後自動分組（男女平均），可指定組長，拖曳微調 |
| 用餐分組 | 每桌人數可調（預設 10 人），每桌也可以單獨設定；顯示素食等飲食需求 |
| 房間分組 | 每間人數可調（預設 4 人），男女自動分開，不同性別無法拖進同一間 |
| 聯絡資料 | 學生手機、兩位緊急聯絡人，加上隨隊人員與飯店電話 |
| 點名表 | 依「基本資料」設定的點名時段產生勾選欄，可依座號／活動組／房間排序 |
| 特殊照護 | 彙整飲食、過敏、醫療、暈車等需注意的學生 |

「列印本頁」只印目前頁面，「全部列印」一次印出所有名單與分組（名單、聯絡資料、點名表會自動使用橫向 A4）。

## 匯入欄位

第一列為欄位名稱：`座號, 姓名, 性別, 學生手機, 緊急聯絡人1, 關係1, 電話1, 緊急聯絡人2, 關係2, 電話2, 飲食, 過敏/醫療, 備註`。
可在「學生名單」頁下載範本。Big5 編碼的 CSV 與被 Excel 去掉開頭 0 的手機號碼都會自動處理。
